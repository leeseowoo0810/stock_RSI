# 미국 10대 주식 실시간 RSI & 매수 랭킹 모바일 웹앱

미국 증시 시가총액 상위 10대 메가캡 주식의 실시간 14일 RSI(상대강도지수)와 종합 매수 적합도 순위를 스마트폰에서 한눈에 볼 수 있도록 설계된 모바일 퍼스트 웹 서비스입니다.

---

## 📱 주요 화면 및 기능

1. **상단 실시간 시계 & 미국 시장 운영 상태**
   - **미국 동부 시간 (ET / New York)**: 서머타임(EDT/EST) 자동 반영 실시간 초 단위 시계
   - **한국 시간 (KST)**: 동시 표기
   - **시장 상태 인디케이터**:
     - 🟢 **정규장 진행 중**: 09:30 ~ 16:00 ET (마감까지 남은 시간 카운트다운)
     - 🟡 **프리마켓 진행 중**: 04:00 ~ 09:30 ET (정규장 개장까지 카운트다운)
     - 🔵 **애프터마켓 진행 중**: 16:00 ~ 20:00 ET
     - ⚪ **장 마감 / 주말 휴장**: 다음 세션 대기

2. **미국 10대 대표 종목 트래킹**
   - `NVDA` (엔비디아)
   - `AAPL` (애플)
   - `MSFT` (마이크로소프트)
   - `AMZN` (아마존)
   - `GOOGL` (알파벳 구글)
   - `META` (메타)
   - `TSLA` (테슬라)
   - `BRK-B` (버크셔 해서웨이)
   - `AVGO` (브로드컴)
   - `LLY` (일라이 릴리)

3. **실시간 RSI(14) 및 시각적 게이지 바**
   - 14일 Wilder's Smoothing 공식 기반 정밀 RSI 산출
   - 0(과매도 녹색) ~ 30 ~ 70 ~ 100(과열 적색) 그라데이션 트랙 위에 현재 주가의 위치 포인터 표시
   - 원터치 터치 시 **최근 14일간 RSI 추세 미니 SVG 스파크라인 차트** 노출

4. **실시간 매수 최적 순위 (1위 ~ 10위) 알고리즘**
   - RSI 과매도 여부 + 20일 이동평균선(SMA20) 대비 눌림목 깊이 + 당일 등락률을 결합한 100점 만점 매수 점수 산출
   - 상태 배지:
     - 💎 **적극 매수 (RSI < 30)**: 단기 급락/과매도로 기술적 반등 확률 최상
     - 🟢 **분할 매수 (RSI 30~40)**: 건전한 조정 구간 분할 매수 적기
     - 🟡 **중립 관망 (RSI 40~60)**: 추세 유지 구간
     - 🟠 **매수 주의 (RSI 60~70)**: 상승 피로감 누적
     - 🔴 **과열 위험 (RSI > 70)**: 추격 매수 금지, 차익 실현 고려

5. **스마트폰 원터치 접속 기능**
   - PC와 스마트폰이 동일한 Wi-Fi에 연결되어 있을 경우, 화면 상단의 스마트폰 아이콘을 누르면 휴대폰 브라우저(Safari, Chrome 등)에서 접속할 수 있는 주소(`http://[로컬IP]:8000`)를 즉시 확인 및 복사할 수 있습니다.
   - 모바일 브라우저 메뉴에서 **'홈 화면에 추가'**를 누르면 스마트폰 앱처럼 사용할 수 있습니다.

## 🚀 실행 방법

### 방법 1. 더블 클릭 실행 (Windows)
- 프로젝트 폴더의 `run.bat` 파일을 더블 클릭하면 자동으로 필요한 패키지를 설치하고 서버를 실행합니다.

### 방법 2. 터미널 명령어로 실행
```bash
cd C:\Users\CKIRUser\.gemini\antigravity\scratch\us-stock-rsi-tracker

# 1. 패키지 설치
pip install -r requirements.txt

# 2. 서버 실행
python app.py
```

브라우저에서 접속:
- PC: `http://localhost:8000`
- 스마트폰 (같은 Wi-Fi): 터미널에 출력되는 `http://[로컬IP]:8000` 주소로 접속
