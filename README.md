# 미국 10대 주식 RSI 데스크 (1분봉 / 일봉)

미국 시가총액 상위 10개 종목의 **1분봉 RSI(14)** 및 **일봉 RSI(14)** 를 제공하는 웹사이트입니다.

- **1분봉 RSI (`index.html`)**:
  - 프리마켓(04:00–09:30 ET), 정규장(09:30–16:00 ET), 애프터마켓(16:00–20:00 ET) 동안 1분봉으로 주가와 RSI를 실시간 재계산합니다.
  - 거래 마감·주말·휴장일에는 가장 최근 거래 세션의 마지막 체결 1분봉을 유지합니다.
- **일봉 RSI (`daily.html`)**:
  - 정규장 종가(최근 1년치 일봉 데이터)를 기준으로 일봉 Wilder RSI(14)를 산출합니다.
  - 정규장 진행 중에는 당일 실시간 일봉을 반영하여 스윙 및 중기 추세 분석에 활용할 수 있습니다.
- **페이지 간 간편 이동**:
  - 상단 네비게이션 탭(`⚡ 1분봉 RSI`, `📅 일봉 RSI`)을 통해 1클릭으로 자유롭게 페이지를 전환할 수 있습니다.
- **동일한 핵심 알고리즘 적용**:
  - **실시간 매수 추천 TOP 3 & 매도 주의 TOP 3 보드**: 단기/일간 과매도 반등 후보 및 과열 차익실현 후보를 한눈에 요약합니다.
  - **정렬 필터 탭**: 기본 시가총액 순, 매수 추천 순(RSI 낮은 순), 매도 주의 순(RSI 높은 순)으로 카드를 즉시 재정렬할 수 있습니다.
  - **실시간 액션 시그널 뱃지**: 각 종목 카드에 매수/매도 순위 및 RSI 구간별 트레이딩 가이드를 동일한 기준으로 표시합니다.
