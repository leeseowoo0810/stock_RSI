# 미국 10대 주식 1분 RSI 데스크

미국 시가총액 상위 10개 종목의 **1분 RSI(14)** 를 보여주는 정적 웹사이트입니다.

- **프리마켓(04:00–09:30 ET), 정규장(09:30–16:00 ET), 애프터마켓(16:00–20:00 ET)** 동안 **1분마다** 실시간 1분봉으로 주가와 RSI를 다시 계산합니다.
- 거래 마감·주말·휴장일에는 **가장 최근 거래 세션의 마지막 체결 1분봉**을 유지합니다.
- 미국 동부시간, 한국시간, 각 시장 세션(프리/정규/애프터/마감) 상태를 실시간 표시합니다.
- **실시간 주가 반영**: 프리마켓 및 애프터마켓의 장외 체결가와 등락률을 즉시 반영합니다.
- **실시간 매수 추천 TOP 3 & 매도 주의 TOP 3 보드**: 단기 과매도 반등 후보 및 과열 차익실현 후보를 한눈에 요약합니다.
- **정렬 필터 탭**: 기본 시가총액 순, 매수 추천 순(RSI 낮은 순), 매도 주의 순(RSI 높은 순)으로 카드를 즉시 재정렬할 수 있습니다.
- **실시간 액션 시그널 뱃지**: 각 종목 카드에 체결 세션(PRE/REG/POST), 매수/매도 순위 및 구간별 트레이딩 가이드를 표시합니다.
