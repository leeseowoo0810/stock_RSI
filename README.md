# 미국 10대 주식 1분 RSI 데스크

미국 시가총액 상위 10개 종목의 **1분 RSI(14)** 를 보여주는 정적 웹사이트입니다.

- 정규장(09:30–16:00 ET)에는 **1분마다** 최신 1분봉으로 RSI를 다시 계산합니다.
- 장 마감·주말·휴장일에는 **가장 최근 정규장 마지막 1분봉**을 유지합니다.
- 미국 동부시간, 한국시간, 정규장 개장 여부를 함께 표시합니다.

## 종목

NVDA, AAPL, GOOGL, MSFT, AMZN, AVGO, META, TSLA, BRK-B, MU

(비상장·외국 기업을 제외한 미국 상장 시가총액 상위 종목 기준)

## GitHub Pages에 올리기

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. 저장소 **Settings → Pages**에서 Source를 `main` 브랜치, `/ (root)` 로 설정합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 로 접속합니다.

빌드 과정은 없습니다. `index.html`이 시작 페이지입니다.

## 로컬에서 보기

브라우저 보안 정책 때문에 `index.html`을 파일로 바로 열면 시세 호출이 막힐 수 있습니다. 폴더에서 간단한 서버를 띄우세요.

```bash
python -m http.server 8080
```

그다음 `http://localhost:8080` 으로 접속합니다.

## 참고

시세는 Yahoo Finance 차트 API의 1분봉을 사용합니다. CORS 제한이 있으면 공개 프록시를 순서대로 시도합니다. 투자 권유가 아닌 참고용 화면입니다.
